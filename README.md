**Course:** LIS4032 Temas Selectos 1 (Machine Learning), UDLAP, Fall 2026
**Topic:** early prediction of student dropout (Dropout / Enrolled / Graduate) at the end of the first semester.

## Python version and installation

- Python 3.13 (tested with 3.13.17). Versions of every library are pinned in `requirements.txt`.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Data access

- Source: UCI Machine Learning Repository, *Predict Students' Dropout and Academic Success* (dataset 697), version published 2021, license CC BY 4.0.
- Link: https://archive.ics.uci.edu/dataset/697
- Exact file: `data.csv` (semicolon-separated, 4,424 rows, 37 columns) from the zip *predict+students+dropout+and+academic+success.zip*.
- The file is already included in `data/data.csv`. To download it again: open the link, click **Download**, unzip and copy `data.csv` into `data/`.
- Reference: Realinho, V., Machado, J., Baptista, L., & Martins, M. V. (2022). Predicting student dropout and academic success. *Data, 7*(11), 146. https://doi.org/10.3390/data7110146

## Execution

```bash
jupyter notebook EquipoXX_Parte1.ipynb      # then Kernel > Restart & Run All
# or, without opening it:
jupyter nbconvert --to notebook --execute --inplace EquipoXX_Parte1.ipynb
```

All paths are relative: run the notebook from this folder. The notebook regenerates
`diccionario_variables.csv`, `particiones.csv`, `figures/` and `results/`.

## Seeds and splits

- `SEED = 42` for the splits and for every model with randomness.
- `student_id` is the 0-based row number of `data/data.csv`. With `particiones.csv` the split
  (70 % train / 15 % validation / 15 % test, stratified by target) can be rebuilt exactly.
- The test set is reserved for Part 2 and is not evaluated in this notebook.

## Approximate runtime

Under 1 minute on a regular laptop (the slowest models are SVC and the random forest, a few seconds each).
